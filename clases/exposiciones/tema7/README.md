# Tema 7: Costos I/O y comparación B-Trees vs B+ Trees

## Descripción

Este tema compara el rendimiento y costos de I/O entre árboles B y B+, destacando las ventajas de B+ Trees en consultas de rango y acceso secuencial debido a la segregación de capas y el encadenamiento de hojas. Se analiza el fan-out, splits, fill factor y aplicaciones en sistemas modernos.
