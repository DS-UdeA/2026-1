# Tema 8: Motivación Espacial y KD-Trees

## Descripción

Este tema introduce la motivación para estructuras de datos espaciales y explica los KD-Trees, incluyendo su construcción, operaciones de inserción y eliminación, búsqueda de vecino más cercano y aplicaciones en consultas de rango multidimensionales.
