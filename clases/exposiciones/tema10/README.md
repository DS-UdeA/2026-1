# Tema 10: Búsqueda espacial, rango y vecinos

## Descripción

Este tema aborda la búsqueda espacial en bases de datos y sistemas de información geográfica. Incluye los conceptos de consultas por rango (Range Query), búsqueda de vecinos más cercanos (Nearest Neighbor Search), eficiencia de índices espaciales y aplicaciones reales en navegación, logística, robótica y análisis geoespacial.
