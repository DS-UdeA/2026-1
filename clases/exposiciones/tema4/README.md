# Tema 4: B+Tree Búsqueda y Range Queries

## Descripción

Este tema cubre las operaciones de búsqueda en B+Tree y los range queries, fundamentales para la recuperación eficiente de datos en sistemas de bases de datos. Se exploran los algoritmos de búsqueda, recorrido de árboles y consultas por rangos.
