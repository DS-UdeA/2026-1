# Tema 9: Quadtrees y R-Trees

## Descripción

Este tema explora las estructuras de datos Quadtrees y R-Trees para indexar datos espaciales, incluyendo su funcionamiento, ventajas, desventajas y aplicaciones en sistemas de mapas y bases de datos geográficas.
